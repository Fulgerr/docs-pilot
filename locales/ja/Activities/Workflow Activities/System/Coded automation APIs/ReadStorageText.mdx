

ストレージ テキストを読み込み
===============

Orchestrator で指定したストレージ バケットからファイルをダウンロードして String 型変数に格納します。

オーバー ロード
========

ReadStorageText\(String, String\)Orchestrator のストレージ バケットにある特定のファイルのコンテンツを返します。ReadStorageText\(String, String, String\)指定した Orchestrator フォルダーにある Orchestrator ストレージ バケットにある特定のファイルの内容を返します。ReadStorageText\(String, String, String, String, Int32\)エンコード名を入力してタイムアウト \(ミリ秒\) を設定するときに、Orchestrator のストレージ バケットにある特定のファイルのコンテンツを返します。
